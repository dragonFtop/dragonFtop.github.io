# 二维数组中的查找

# 题目描述

在一个二维数组 array 中（每个一维数组的长度相同），每一行都按照从左到右递增的顺序排序，每一列都按照从上到下递增的顺序排序。请完成一个函数，输入这样的一个二维数组和一个整数，判断数组中是否含有该整数。

示例数组：

  • 给定 target = 7，返回 true。
  • 给定 target = 3，返回 false。

# 数据范围

矩阵的长宽满足 0≤n,m≤5000 \le n,m \le 5000≤n,m≤500，矩阵中的值满足 −109≤val≤109-10^9 \le val \le 10^9−109≤val≤109

# 进阶要求

空间复杂度 \(O(1)\)，时间复杂度 \(O(n+m)\)

# 示例

示例 1
输入： 7,[[1,2,8,9],[2,4,9,12],[4,7,10,13],[6,8,11,15]]
返回值： true
说明：存在 7，返回 true

示例 2
输入： 1,[[2]]
返回值： false

示例 3
输入： 3,[[1,2,8,9],[2,4,9,12],[4,7,10,13],[6,8,11,15]]
返回值： false
说明：不存在 3，返回 false

# 解法 1：阶梯搜索（最优，满足进阶要求）

思路：选择右上角作为起点

  1. 如果当前元素 == target，找到，返回 True
  2. 如果当前元素 > target：说明这一列下面所有数都更大，向左移动一列（ col -=1 ）
  3. 如果当前元素 < target：说明这一行左边所有数都更小，向下移动一行（ row +=1 ）
    终止条件：越界，说明不存在，返回 False
    时间：\(O(n+m)\)，空间：\(O(1)\)

# 解法 2：逐行二分查找

思路：每一行都是有序数组，遍历每一行，对单行使用二分搜索。
时间：O(nlog⁡m)O(n \log m)O(nlogm)，空间：\(O(1)\)
适合理解二分，但相比阶梯搜索效率差一点。
