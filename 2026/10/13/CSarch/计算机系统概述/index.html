# 计算机系统概述（第 1 章）

# 1.1 计算机组成与计算机体系结构

计算机组成（Computer Organization）

  • 包含计算机系统的所有物理方面（physical aspects）。
  • 例如：电路设计、控制信号、存储器类型。

计算机体系结构（Computer Architecture）

  • 从程序员视角看到的系统实现的逻辑方面（logical aspects）。
  • 例如：指令集（instruction sets）、指令格式、数据类型、寻址模式（addressing modes）。

一句话区分：组成关心 "硬件怎么搭"，体系结构关心 "程序员看到什么"。

# 1.2 计算机组件

最底层来看，计算机是由三部分组成的设备：

  • 处理器（processor）：解释（interpret）并执行（execute）程序。
  • 存储器（memory）：同时存放数据（data）和程序（programs）。
  • 在计算机与外部世界之间传送数据的机制（如 I/O）。

# 硬件与软件的对等原则（Principle of Equivalence）

  • 软件能完成的任务，硬件也能完成；硬件直接执行的操作，软件也能完成。
  • 前提假设：速度不是问题（speed is not a concern）。
  • 例如：某公司 2023 年推出的固态密码加速卡，基于高性能 FPGA 设计，计算固态密码密文速度比纯软件提升 2 个数量级。

# 从一则广告理解系统参数

广告规格：Intel i7 Quad Core 3.9GHz / 1600MHz 32GB DDR3 SDRAM / 128KB L1 cache 2MB L2 cache / 1TB SATA hard drive 7200 RPM / USB、PCI 端口等。逐项解释：

  • 微处理器（microprocessor）是系统的 "大脑"，执行程序指令。
  • 硬盘容量（硬盘容量）决定能存储的数据与程序规模；转速（RPM）越快，向 RAM 送数据越快。
  • 端口（ports）在系统与外部设备之间传输数据。
  • DDR SDRAM：同步动态（synchronous dynamic）RAM。
  • 两级缓存（cache）：L1 比 L2 更小、（通常）更快；缓存容量用 KB、MB 衡量。
  • Serial ATA（串行高级技术配置）：描述硬盘与其他系统组件的接口方式。
  • DVD 可存约 4.7GB，+/-RW 表示可重写（rewritable）。
  • 系统总线（system buses）可由专用 I/O 总线扩展；PCI（peripheral component interface，外围组件接口）就是这样一种总线；PCIe 设备如显卡（video card）、声卡（sound card）。
  • 串行端口（serial ports）在一两条数据线上以脉冲序列发送数据；并行端口（parallel ports）在至少八条数据线上同时发送；USB（通用串行总线）是智能串行接口，自配置（self-configuring），支持 "即插即用"。

# 1.4 标准化组织

  • ISO（国际标准化组织）：制定从螺纹到胶卷的全球标准，对计算机硬件软件标准影响很大。注意：ISO 不是缩写，来自希腊语 isos，意为 "equal"。
  • ITU（国际电信联盟）：关注电信系统的互操作性（interoperability），包括数据通信与电话。
  • IEEE（电气电子工程师学会）：促进全球电气工程界利益；制定计算机组件、数据表示、信号协议等标准。
  • 国家级组织：ANSI（美国）、BSI（英国）、中国国家标准化管理委员会（由国家市场监督管理总局领导）。

# 1.5 计算机发展历程

计算机演化通常分为四、五代（以下年代均为近似值）。

# 第零代：机械计算机（1642 - 1945）

  • 计算钟（Calculating Clock）——Wilhelm Schickard（1592-1635）
  • 帕斯卡加法器（Pascaline）——Blaise Pascal（1623-1662）
  • 差分机（Difference Engine）——Charles Babbage（1791-1871），机械史上的巅峰之作
  • 穿孔制表机（Punched card tabulating machines）——Herman Hollerith（1860-1929）

# 第一代：真空管计算机（1945 - 1953）

  • Atanasoff Berry Computer（1937-1938）：解线性方程组（linear equations），爱荷华州立大学的 John Atanasoff 与 Clifford Berry。
  • ENIAC（Electronic Numerical Integrator and Computer）：宾夕法尼亚大学 John Mauchly 与 J. Presper Eckert，1946 年 —— 第一台通用计算机。
  • IBM 650（1955）：第一台批量生产的计算机，1969 年停产。
  • 同期厂商：UNIVAC、ERA、CRC。

# 第二代：晶体管计算机（1954 - 1965）

  • IBM 7094（科学计算）与 1401（商用）；DEC PDP-1；Univac 1100；CDC 1604 等。
  • 这些系统之间几乎没有架构相似性（few architectural similarities）。

# 第三代：集成电路计算机（1965 - 1980）

  • IBM 360；DEC PDP-8 与 PDP-11；Cray-1 超算。
  • 这一时期 IBM 获得了行业压倒性的统治地位。

# 第四代：超大规模集成电路计算机（1980 - ？）

  • VLSI（Very Large Scale Integration）单芯片集成超过 10,000 个元件。
  • 催生了微处理器（microprocessor）：第一款是 4 位 Intel 4004；其后的 8080、8086、8088 催生了 "个人计算"（personal computing）概念。

# 摩尔定律与洛克定律

  • 摩尔定律（Moore's Law，1965）：Intel 创始人 Gordon Moore 提出 ——"集成电路中晶体管密度每年翻一番"；现代版本："硅芯片密度每 18 个月翻一番"。但这条 "定律" 不可能永远成立。
  • 洛克定律（Rock's Law）：Intel 投资人 Arthur Rock——"建造半导体工厂的资产设备（capital equipment）成本每四年翻一番"。1968 年建一个新芯片厂约 $12,000；2012 年在建芯片厂花费超过 50 亿美元 —— 超过一些国家的 GDP（如巴巴多斯、毛里塔尼亚、卢旺达）。

# 1.6 计算机层次结构

计算机除了芯片还需要软件才能工作。编写复杂程序采用 "分而治之（divide and conquer）" 的方法，每个模块解决一个小问题；复杂计算机系统也采用类似技术 —— 一系列虚拟机层次（virtual machine layers）。

  • 第 6 层 用户层（User Level）：程序执行与用户界面层，我们最熟悉的层次。
  • 第 5 层 高级语言层（High-Level Language Level）：用 Python、C、Pascal、Lisp、Java 等语言写程序时交互的层次。
  • 第 4 层 汇编语言层（Assembly Language Level）：处理第 5 层产生的汇编语言，以及直接在该层编写的指令。
  • 第 3 层 系统软件层（System Software Level）：控制系统上执行的进程；保护系统资源；汇编指令通常不经修改直接穿过此层。
  • 第 2 层 机器层（Machine Level）：又称指令集架构（ISA）层；由特定于该机器架构的指令组成；机器语言程序不需要编译器、解释器或汇编器（assembler）。
  • 第 1 层 控制层（Control Level）：控制单元（control unit）译码并执行指令、在系统中搬移数据；控制单元可以是微程序的（microprogrammed）或硬接线的（hardwired）。微程序是用低级语言编写、由硬件实现的程序；硬接线控制单元由直接执行机器指令的硬件组成。
  • 第 0 层 数字逻辑层（Digital Logic Level）：数字电路（芯片）所在层；电路由门和线路构成，实现其他所有层次的数学逻辑。

每一层虚拟机都是下一层的抽象（abstraction）：每层的机器执行自己的指令，需要时调用更低层的机器完成任务，最终由计算机电路完成工作。

# 1.7 计算即服务：云计算

  • 与其自建数据中心，不如从别人的数据中心购买计算服务（buy computing services），通过 Internet 连接 —— 这就是云计算（Cloud Computing）。
  • "云" 是传统上用于表示 Internet 的视觉隐喻（visual metaphor）。
  • 计算机系统的最终目的是向用户交付功能（deliver functionality）；用户通常不关心有多少 TB 存储、多少 GHz 主频。
  • 弹性（elasticity）：资源可按需增加和移除；按使用量付费（pay for what you use）。
  • 虚拟化（virtualization）是弹性的使能技术：你拥有的是一台 "逻辑" 机器，它可以跨越（span）多台物理机，也可以只占一台物理机的一部分。

# 三种服务模型

# 1.8 冯・诺依曼模型

  • ENIAC 的发明者 John Mauchly 与 J. Presper Eckert 设想了一种能把指令存储在存储器中的计算机（store instructions in memory）；这一思想的发明后来被归功于（ascribed to）数学家 John von Neumann—— 他是 Mauchly 与 Eckert 的同时代人。
  • 程序存储计算机（stored-program computers）被称为 ** 冯・诺依曼架构（von Neumann Architecture）** 系统。

# 系统组成

  • 今天的程序存储计算机具有三个硬件系统：CPU、主存系统、I/O 系统。
  • 具备顺序指令处理（sequential instruction processing）的能力。
  • CPU 与主存之间只有一条数据通路（single data path）—— 这条单通路被称为冯・诺依曼瓶颈（von Neumann bottleneck）。

# 取码 - 译码 - 执行周期（fetch-decode-execute cycle）

  1. 控制单元用程序计数器（program counter，PC）确定指令位置，从存储器中取出下一条指令。
  2. 指令被译码为 ALU 能理解的 "语言"；执行所需的数据操作数（data operands）从存储器取出并放入 CPU 内的寄存器（registers）。
  3. ALU 执行指令，把结果放回寄存器或存储器。

对比：ENIAC 的所有编程都在数字逻辑层完成 —— 通过插拔插头和电线（moving plugs and wires）来配置硬件，每种问题类型都需要不同的硬件配置，一个 "简单" 问题也要熟练技师耗费数天。

# 1.9 非冯・诺依曼模型

  • 有些系统对数据和指令使用独立总线（separate buses）—— 称为哈佛架构（Harvard architecture）。
  • 另一些非冯・诺依曼系统提供专用处理器（special-purpose processors），替主 CPU 分担工作。
  • 更彻底的背离包括：数据流计算（dataflow computing）、量子计算（quantum computing）、细胞自动机（cellular automata）、并行计算（parallel computing）。
  • 传统程序存储计算机多年来做过许多增量改进（专用总线、浮点单元、缓存）；但计算能力的巨大提升需要背离经典冯・诺依曼架构，增加处理器（adding processors）是途径之一。

# 1.10 并行计算

  • 并行处理让计算机同时处理问题的多个子部分（simultaneously work on subparts）。
  • 多核处理器（multicore processors）：两个或多个处理器核心共享一个晶模（die）；每个核心有自己的 ALU 和寄存器组，但所有处理器共享存储器和其他资源。
  • 双核（dual core）与双处理器（dual processor）不同：双处理器机器有两个处理器，各自独立插在主板上。
  • 多核系统带来多任务（multitask）能力，例如一边浏览网页一边刻录 CD。
  • 多线程应用把小的进程 / 线程（threads）分布到一个或多个处理器上以提高吞吐量；需要新的编程语言才能完全发挥多处理器能力。

# 并行计算发展小史

  • 1960 年代末：高性能计算机系统使用双处理器提高吞吐量。
  • 1970 年代：出现 32 个处理器的超级计算机系统。
  • 1980 年代：1000 个处理器的超级计算机。
  • 1999 年：IBM 发布 Blue Gene 系统，包含超过 100 万个处理器。

# 1.11 并行主义：机器智能的驱动器

  • 对机器智能（machine intelligence）的追求已持续 300 多年。
  • 20 世纪见证了第一台在国际象棋上达到 "人类大师（grandmaster）" 水平的机器：1997 年深蓝（Deep Blue）击败加里・卡斯帕罗夫（Garry Kasparov，俄罗斯国际象棋特级大师、前世界冠军）。但它依赖蛮力（brute force）解法，令人印象深刻却谈不上 "智能"。
  • 真正机器 "智能" 的定义至少应包括：
    1. 无需直接人类介入（intervention）即可获取新知识的能力；
    2. 使用不完整甚至矛盾（contradictory）的信息解决问题的能力。
  • IBM 的 Watson 做到了这点：2011 年 2 月 16 日击败两名人类 Jeopardy!（美国电视答题节目）冠军。
  • Watson 采用大规模并行架构（massively parallel architecture），称为 DeepQA（Deep Question and Answer）：
  • 后续发展：AlphaGo 与李世石（2016）的围棋人机大战，标志并行计算 + 深度学习的机器智能新阶段。
