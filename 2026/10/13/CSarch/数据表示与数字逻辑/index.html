# 2.1 数据表示基础

# 比特、字节与字

  • 位（bit，比特）：计算机中最基本的存储单位，只有两种状态：开 / 关（on/off）、高 / 低电压（high/low voltage）。
  • 字节（byte）：8 个比特，是内存中最小可寻址单元（smallest addressable unit），通过地址（location）取回（retrieve）。
  • 字（word）：一串连续的字节（contiguous group of bytes），常见字长为 16、32、64 位；按字寻址（word-addressable）的机器以字为访问单位。
  • 半字节（nibble）：4 个比特；一个字节可分为高半字节（high-order nibble）与低半字节（low-order nibble）。

# 2.4 浮点数表示（Floating-Point Representation）

浮点数由三部分组成：符号（Sign）、指数（Exponent）、有效位数（Significand）。

  • 指数占的位数决定范围（range）；
  • 有效位占的位数决定精度（precision）。

# 浮点异常

  • 上溢（overflow）：结果超出最大可表示范围；
  • 下溢（underflow）：结果小于最小可规格化数；
  • 除零（division by zero）。

系统宁可崩溃，也不要产生貌似正确（plausible）的错误结果。

# IEEE-754 标准

  • 单精度（single precision）：32 位 = 1 符号位 + 8 位指数（偏移 127）+ 23 位有效位；
  • 双精度（double precision）：64 位 = 1 符号位 + 11 位指数（偏移 1023）+ 52 位有效位。

# 2.5 字符编码（Character Codes）

  • 最早的字符码是 6 位编码。
  • BCD：大型机（mainframes）上使用的字符编码。
  • ASCII：使用 7 位，包含 32 个控制字符、10 个数字、52 个字母（大小写）、32 个特殊字符，以及空格。
  • Unicode：16 位编码，向下兼容 ASCII（lowest-numbered section 就是 ASCII 字符），是 Java 语言的默认编码。

Unicode 编码空间（codespace）划分为六个部分：

部分大小编码范围
字母数字（Alphanumerics）81920000–1FFF
符号（Symbols）40962000–2FFF
CJK（中日韩符号）40963000–3FFF
汉字（Han）409604000–DFFF
汉字扩展（Han Expansion）4096E000–EFFF
用户定义（User Defined）4095F000–FFFE

编号最小的部分是 ASCII；编号最大的一部分是用户定义区。

# 2.6 检错与纠错（Error Detection and Correction）

没有任何传输或存储介质是 100% 完美的；出错的可能性随数据规模以几何级数增长。传输、存储与取回（retrieval）数据时都必须考虑检错。

# 循环冗余校验（CRC, Cyclic Redundancy Check）

  • 校验和（checksums）与 CRC 都属于系统性检错（systematic error detection）。
  • 附加在数据后的差错控制位（error control bits）称为校验子（syndrome）。
  • CRC 本质上是用模 2 域上的多项式（polynomials over a mod-2 field）做除法。

计算规则：设数据串 s 长 n 位，模式（生成多项式）p 长 k 位。

  1. 在 s 后面补 k−1 个 0；
  2. 用模 2 除法（异或代替减法）除以 p，得余数 r；
  3. 把 r 附加在原始数据后发送。

例：数据 1111101，模式 1101（对应多项式 X^3 + X^2 + 1）：

接收端把收到的码字再除以 1101：余数全为 0 → 判定正确。

# 汉明码与 Reed-Solomon 码

  • 汉明码（Hamming codes）：通过增加冗余位 / 奇偶校验位（parity bits）来检错纠错。
  • Reed-Solomon 码：擅长处理突发错误（burst errors），例如 CD-ROM 表面的划伤。

# 为什么需要纠错码？

传输出错可以请求重传（retransmission），但内存 / 存储中数据只有一份副本，无法重传 —— 因此需要纠错码（error correcting codes）来保证数据完整性（integrity）。

# 汉明距离（Hamming Distance）

  • 两个码字之间不同比特的个数称为汉明距离；
  • 一组码的最小汉明距离 d_min 决定其检错纠错能力：
    • 检测 d 个错误：d_min ≥ d + 1
    • 纠正 t 个错误：t = ⌊(d_min − 1) / 2⌋

例：码组 {10111001, 01011101, 10100111, 01010110} 的最小汉明距离为 3 → 可以纠正 1 位错误。

  • 真值表示例：F (x, y, z) = xz' + y，为便于计算可在表中列出中间列（z'、xz' 等辅助列）。
