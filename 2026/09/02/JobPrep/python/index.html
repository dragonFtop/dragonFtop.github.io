# 生成器函数（yield）

在实例化时不会自动运行，需要使用 next 来运行，yield 会返回数据并将函数停止在此处，待下次 next 继续运行并停止

好处：当遇到巨大数据的时候不用一次性在内存中生成全部数据占用大量内存，主打一个用一次取一次
