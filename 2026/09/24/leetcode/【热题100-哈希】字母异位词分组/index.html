# 字母异位词分组

# 题目

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

字母异位词：两个字符串所含字母种类、每个字母出现次数完全一致，仅字母顺序不同。

# 提示

  • 1≤strs.length≤1041 \le \text{strs.length} \le 10^41≤strs.length≤104
  • 0≤strs[i].length≤1000 \le \text{strs[i].length} \le 1000≤strs[i].length≤100
  • strs[i] 仅包含小写英文字母

# 核心知识点：什么能做哈希表（dict）的 key，什么不能

Python 字典 key 要求：可哈希（不可变）

✅ 可以作为 key：

  • 字符串 str
  • 整数 int
  • 元组 tuple （里面所有元素都可哈希）

❌ 不能作为 key：

  • 列表 list （可变）
  • 字典 dict （可变）
  • 集合 set （可变）

本题思路：给每一个字符串生成一个 **“特征 key”**，异位词的特征 key 一定相同；哈希表 value 存同组字符串列表。

# 方法一：排序字符串作为 key（代码简洁，面试好写）

# 思路

同一个字母异位词，把字符排序之后得到的字符串一定一模一样。
例如 "eat" → 排序得到 "aet" ； "tea" 排序也得到 "aet" 。
排序后的字符串是 str 类型，可以直接当哈希表 key。

# 代码（普通 dict，不依赖 defaultdict）

# 复杂度

  • 设字符串最长长度为 kkk，数组长度 nnn
  • 时间：O(n⋅klog⁡k)O(n \cdot k \log k)O(n⋅klogk)，每个字符串排序耗时 klog⁡kk\log kklogk
  • 空间：O(nk)O(nk)O(nk)

# 优点 & 缺点

✅ 代码短，容易写，不容易出错
❌ 排序有额外 log 开销

# 方法二：26 字母计数，转元组作为 key（效率更高）

# 思路

因为只有小写 a-z，开一个长度 26 的数组，记录每个字母出现次数。

列表 list 不能直接做 key，所以统计完成后把 list 转为 tuple 元组，元组可哈希，作为哈希表 key。

比如 "eat" ：a:1, e:1, t:1，其余字母 0，数组 [1,0,0,...1,...1...] ，转 tuple 作为 key。

# 代码（使用 defaultdict）

# 复杂度

  • 时间：O(n⋅k)O(n\cdot k)O(n⋅k)，只遍历字符计数，无排序
  • 空间：On⋅26+nk=O(nk)On\cdot 26 + nk = O(nk)On⋅26+nk=O(nk)

# 优点 & 缺点

✅ 时间效率更高，适合长字符串
❌ 代码略长，只能用于小写英文字母场景

# 【重点标注】本题各个变量能不能当哈希 key

  1. key = ''.join(sorted(s)) → 字符串 str ✅ 可做 key
  2. count = [0]*26 → 列表 list ❌ 不可做 key
  3. key = tuple(count) → 元组 tuple ✅ 可做 key
  4. 自己手写的频次字典 cnt = {"a":1, "e":1} → dict ❌ 不可做 key；
    如果想使用频次字典当特征： tuple(sorted(cnt.items())) → 转为元组 ✅ 可做 key

# 面试简答对比

  • 排序法：写得快，通用性强（字符不限于小写字母），代价是排序
  • 26 字母计数元组法：线性时间，只适合小写英文字母，速度更快
