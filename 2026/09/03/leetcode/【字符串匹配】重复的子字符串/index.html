# 重复的子字符串

# 题目描述

给定一个非空的字符串 s ，检查是否可以通过由它的一个子串重复多次构成。

示例 1:

  • 输入: s = "abab"
  • 输出: true
  • 解释：可由子串 "ab" 重复两次构成。

示例 2:

  • 输入: s = "aba"
  • 输出: false

示例 3:

  • 输入: s = "abcabcabcabc"
  • 输出: true
  • 解释：可由子串 "abc" 重复四次构成。 (或子串 "abcabc" 重复两次构成。)

提示:

  • 1≤s.length≤1041 \le s.length \le 10^41≤s.length≤104
  • s 由小写英文字母组成

# 方法一：字符串拼接法（巧解）

# 思路

假设字符串 s 是由子串 t 重复 kkk 次构成（k≥2k \ge 2k≥2），即 s=t×ks = t \times ks=t×k。

  1. 将字符串拼接： s + s ，得到 t * 2k 。
  2. 将拼接后的字符串去掉第一个字符、去掉最后一个字符。
  3. 如果原始字符串 s 能够出现在这个截取后的字符串中 → 返回 True ；否则返回 False 。

原理：

  • 如果 k >= 2： (s+s)[1:-1] 的内部一定完整包含 s 。
  • 如果 k=1（字符串本身就是最小单元，无法由子串重复）：截取之后一定找不到原字符串。

# 代码实现

# 复杂度分析

  • 时间复杂度：O(n)O(n)O(n)，字符串拼接、子串查找。
  • 空间复杂度：O(n)O(n)O(n)，存储拼接后的字符串。

# 方法二：暴力枚举法

# 思路

设字符串总长度为 nnn。

  1. 能重复构成的基础条件：子串长度 l 必须是总长度 nnn 的约数，并且 l<nl < nl<n。子串不能等于整个字符串。
  2. 枚举可能的子串长度 l ，范围： 1 ~ n//2 。超过一半长度不可能重复拼接出原字符串。
  3. 如果 n % l == 0 ，计算需要重复次数 times = n // l 。
  4. 拿子串 s[:l] 重复 times 次，和原字符串对比，相等直接返回 True 。
  5. 全部枚举结束都没有匹配，返回 False 。

# 代码实现

# 复杂度分析

  • 时间复杂度：O(n2)O(n^2)O(n2)，最坏情况多次字符串生成与比对。n≤104n\le10^4n≤104 可以 AC。
  • 空间复杂度：O(n)O(n)O(n)，生成拼接的测试字符串。

优点：逻辑直白，容易理解。
缺点：数据量很大时性能较差。

# 方法三：KMP 算法（next 数组，面试重点）

# 核心概念

next 数组（部分匹配表）： next[i] 代表子串 s[0:i+1] 的最长相等前后缀长度。

例： abcabc

  • 前缀： a,ab,abc,abca,abcab
  • 后缀： c,bc,abc,cabc,bcabc
  • 最长相等前后缀： abc ，长度 = 3。

推导结论
设字符串长度 nnn， last_next = next[-1] （整个字符串最长相等前后缀）。
循环节（最小重复子串）长度： cycle = n - last_next 。

  • 如果满足： cycle != n 并且 n % cycle == 0 → 字符串可以由长度为 cycle 的子串重复构成。

# 推导示例

s = abab ，n=4n=4n=4
next 数组最后一位 = 2
cycle =4‑2 =2 。
4%2==04 \%2 ==04%2==0， cycle !=4 → True，循环节长度 2。

s=aba ，n=3n=3n=3
next 数组最后一位 = 1
cycle = 3‑1 =2
3%2≠03\%2 \neq03%2=0 → False。

# 代码实现

# 复杂度分析

  • 时间复杂度：O(n)O(n)O(n)，KMP 构建 next 数组线性遍历。
  • 空间复杂度：O(n)O(n)O(n)，next 数组存储。

优点：最优时间复杂度，面试高频考点。
缺点：KMP 理解门槛高。
